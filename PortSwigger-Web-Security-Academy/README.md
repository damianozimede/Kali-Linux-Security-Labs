# PortSwigger Web Security Academy

This folder documents hands-on labs completed through [PortSwigger's Web 
Security Academy](https://portswigger.net/web-security) — free, industry-respected 
web application security training from the creators of Burp Suite.

This work was assigned by my ICDFA internship coach as supplementary, 
practical reinforcement of web application security concepts covered in 
my formal coursework (INT307: Web Application Security).

## Structure
Labs are organized by topic, following the "Server-side vulnerabilities" 
learning path:

- Path Traversal
- Access Control
- Authentication
- Server-Side Request Forgery (SSRF)
- File Upload Vulnerabilities
- OS Command Injection
- SQL Injection

Each lab folder contains a write-up covering the objective, approach, 
result, and key takeaway for that exercise.

## Why this matters
Unlike guided coursework, these labs are unguided, realistic vulnerability 
scenarios modeled on real-world bugs — testing the ability to independently 
identify and exploit web application security flaws using tools like 
Burp Suite.
